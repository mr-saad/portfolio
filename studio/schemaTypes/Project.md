## **Ratan Bandhej – Bandhani Handicraft E-Commerce Website**

**Ratan Bandhej** is a modern e-commerce platform dedicated to traditional Bandhani handicraft products. The website is designed with a clean UI, smooth browsing experience, and a fully responsive layout to make online shopping simple and fast for users.

The project focuses on showcasing handcrafted Bandhani items with high-quality images, dynamic product rendering, and an optimized checkout journey. I built the entire system from scratch with attention to performance, accessibility, and scalability — suitable for a real-world small business.

---

### **💡 Key Features**

- Fully responsive e-commerce layout
- Dynamic product listing and filtering
- Smooth animations for page transitions and product sections
- Fast loading with image optimization
- CMS-powered product management
- Clean and intuitive UI focused on user experience

---

### **🛠️ Tech Stack**

- **Next.js** – Server-side rendering, routing, and API routes
- **Tailwind CSS** – Fast styling and responsive UI
- **Swiper JS** – Product sliders and image carousels
- **Framer Motion** – Page & component animations
- **Sanity CMS** – Content management and dynamic data fetching
